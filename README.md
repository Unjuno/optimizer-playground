# Optimizer Playground

**動かして、発見する。** 独自の更新規則と損失地形をつくり、ブラウザ内で最適化を実行・観察・比較する実験サイトです。

このリポジトリには **動作する改善版 v0.4.0** が含まれます。デモ用に作った軌跡ではなく、実際の目的関数と勾配を使って計算します。モデルの学習サイトではありません。

## 投稿・共有を含むサーバー版

開発・運営用環境に **Node.js 22以上** が必要です。サイトの利用者にはNodeやPythonのインストールは不要です。

```sh
npm run build
npm start
```

ブラウザで `http://127.0.0.1:3000` を開きます。初回から依存関係のダウンロードは不要です。`npm install` は必要ありません。

通常は同じ端末だけから接続できる設定です。外部公開の構成は [DEPLOYMENT.md](docs/DEPLOYMENT.md) を参照してください。この配布物を実際にデプロイする操作は含みません。公開サイトのURLはまだありません。

## 実装済み

| 領域 | 内容 |
|---|---|
| 30秒の初回体験 | 画面上部のボタンで実行 → Momentumの移動平均係数だけ変えて再実行 → 差を数値・軌跡・損失曲線で比較 |
| 地形 | 7種類のプリセット、数式編集、山・谷を手描きするガウスブラシ |
| オプティマイザ | SGD、指数移動平均型Momentum、Adam、AdamW、Lion、勾配不要のRandom search |
| 自作コード | 条件分岐、ループ、関数、配列・行列、独自の状態、複数の目的関数評価 |
| 視覚編集 | 履歴・方向変換・クリッピング・重み減衰の部品選択からコード生成。適用前に戻せる |
| 空間分析 | 等高線、複数軌跡、勾配と実更新の矢印、候補点の描画。軌跡を選ぶと対応ステップへ移動 |
| 時系列分析 | 損失、出発点勾配、移動平均、更新量、現在点勾配、ユーザー定義の観測値。グラフからステップ選択 |
| 再生 | 一時停止、1更新送り、スクラブ、再生速度。記録から再生するため速度で結果は変化しない |
| 比較 | 同一条件の最大4手法、評価回数、停止理由、計算時間、CSVの明示的な書き出し |
| ゲーム的な評価 | 3地形×3開始点の共通チャレンジ。固定条件でSGDとの比較。スコアは未検証 |
| 共有 | 明示的な同意でコード・条件・数値履歴・チャレンジ結果を投稿し、URLを発行 |
| 削除 | 投稿時の削除キーで削除。サーバーにはキーのハッシュのみ保存 |
| 公開方針 | ログインなし、公開一覧なし、下書き・個人用保存・自動投稿なし。第三者のコードは自動実行しない |

## 初めの実験

1. 画面上部の **「現在の条件で実行」** をクリックすると、今の設定・コードを維持したまま実験できます。初期状態は「細長い谷」でMomentum・SGD・Adamの比較です。
2. Momentumのまま **「β=0.20で比較」** を押すと、移動平均係数だけ変更して再実行します。**前回の結果を破線で重ね**、軌跡と損失曲線の両方で差を見られます。
3. 破線のチェックを切り替えて違いを観察し、「軌跡を調べる」で地形の線をクリックすると、その更新の時系列信号に移動できます。右の時系列グラフからも時刻を選べます。
4. その後、地形・コード・学習率などを自由に編集して再実行します。
5. 共通チャレンジで他の地形にも同じ更新規則を適用します。
6. サーバー版で公開を選んだときだけ、共有URLと削除キーを発行します。

編集すると古い実験結果をクリアします。**例外として、初回体験のβだけを変えた比較**では、その場限りの表示用履歴を保持します。前回の比較軌跡は投稿に含めず、共有されるのは現在の実験です。異なるコードの結果を同じ実験として見せないためです。ページの再読み込みで未投稿の内容は消えます。

## 実装上の境界

- **CPU / JavaScript Number（FP64）のみ**。WebGPU、任意のPython/PyTorch/CUDA、実際のニューラルネット学習は未実装です。
- 自作コードは、ホストJavaScriptの `eval` ではなく、**Acornで構文解析する命令数制限付きインタープリター**で実行します。JavaScript全構文への互換性はありません。
- 現在のタスクは2変数です。行列を状態として扱えますが、行列パラメータを持つ本格的なMuonベンチマークではありません。
- ビジュアル編集は部品選択型です。任意コードを完全にノードに逆変換するエディタではありません。
- スコアはクライアントの自己実行結果です。改ざん耐性のある公式順位や科学的な優位性を保証しません。
- ブラウザメモリ量の実測、複数GPU、分散計算、アカウント、投稿一覧、共同編集は実装していません。
- 自己レビューと自動テストを実施しましたが、**独立した安全性監査ではありません**。

仕様の原案からの変更点は [RELEASE.md](docs/RELEASE.md) にあります。

## テスト

```sh
npm test                 # 数値計算、インタープリター、共有HTTP API、ビルド
npm run build            # distと単体HTMLを再生成
```

ブラウザテストにはPythonとPlaywrightが必要です（開発者だけ）。

```sh
python -m pip install playwright
python -m playwright install chromium
npm run test:browser-offline   # 外部ナビゲーションせず、単体HTMLをChromium内で実行
npm run test:browser-regressions # エラー停止時の比較・操作テスト
npm run test:browser-inspection # 空間・時系列の同期とCSV検証
npm run test:e2e               # 通常の環境向け：実HTTP共有・削除・再表示
```

`CHROMIUM_PATH` で使用するChromiumを指定できます。未指定時はシステムの `chromium`、なければPlaywrightのインストール先を使います。検証の実績と制約は [VERIFICATION.md](docs/VERIFICATION.md) を参照してください。

## 構成

```text
public/          HTMLとスタイル
src/core/        数式・解析勾配・地形・更新規則・評価・投稿形式
src/runtime/     制限付きインタープリターとWeb Worker
src/ui/          UI状態、Canvasによる空間／時系列描画
server/          明示的投稿と共有・削除、期限付きファイル保存
vendor/          Acorn 8.15.0とMITライセンス
scripts/         依存ダウンロードなしのビルド
release/         単体で開けるHTML
dist/           サーバー用の生成済みファイル
tests/          自動テスト
```

数値最適化、科学的可視化、制限付き言語実行を分離して実装しています。教育・観察から共同アルゴリズム探索へ拡張できる構成ですが、現版のスコアだけで実用上の性能を主張しないでください。

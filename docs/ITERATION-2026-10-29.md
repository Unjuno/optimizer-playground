# v0.3.0 — 初回実験の導線と因果比較

目的: 初見ユーザーが、コードを読まずにブラウザ内で最適化を動かし、設定1項目を変えることで挙動の差を発見できるようにする。実際のモデル学習・GPU・無制限のPython実行は対象外。公開リポジトリとWork/Sitesデプロイは別工程。

## 変更

1. ヒーロー領域に初回実行ボタンを設置。初期設定もユーザーが編集中の設定も黙って上書きしない。クリックまで実行しない。
2. Momentumで実行後に移動平均の保持係数 β のみを 0.90→0.20（0.20の場合は0.90）へ変更し、そのまま再実行できる。
3. 同じ地形・開始点・コード・seed・予算での最良損失／スコアの比較を文章で表示。良し悪しはその条件での**観測**に限定し、一般的な性能を保証しない。
4. 前回軌跡を山吹色の破線で空間・損失履歴に重ね、チェックボックスで切替。前回の履歴はこのページのメモリ内だけに置き、共有データには含めない。
5. 共有ダイアログで前回比較軌跡が投稿されないことを明記。
6. コード、地形、予算などを編集した場合、古い比較データを破棄。既存のチャレンジ採点、共有API、エンジンは変更しない。
7. 初回操作、二つのグラフの表示差、比較破棄、モバイルのタッチ領域、オフライン動作をChromiumの回帰テストに追加。

## 設計上の制約・注意

- 比較はMomentumの一つのハイパーパラメータだけを変える体験。自作コードの場合、βを使う保証がないためボタンは表示しない。
- 破線は同一条件で再実行した局所的な比較であり、世界順位や統計的有意性を示さない。
- チャレンジおよび共有スコアには従来と同じ実行結果を使用し、破線データは投稿しない。永続化なし。
- キーボードのみでのCanvas描画の代替操作、第三者コードの独立セキュリティ監査、HTTPSブラウザでの投稿→取得→削除の完全な通し検証は残課題。

## 追加検証

`npm test`、`npm run build`、`npm run test:browser-offline` で回帰確認。CPU・JavaScript Number（FP64）、Linux・Node.js 22.16.0・headless Chromiumを使用。実行時間・GPU速度の比較は行わない。

## 2026-10-30 v0.3.1 不具合回帰検証

下記の不具合は、修正前に失敗するテストを確認したうえで修正した。

- 欠落／非有限の最終損失を持つ記録にスコアが付く → 採点不可（`null`）に変更。
- 共通9課題と異なる地形・開始点・seed、平均値と内訳の不一致、ソースコードの不一致、失敗しているのに正の得点という共有記録 → 投稿時に形式不正として拒否。
- Momentumの係数変更で次の実験が範囲外停止すると、成功していた前回の軌跡まで見えなくなる → 比較オーバーレイと再生タイムラインを保持。
- 範囲外停止が `RESULT` と表示される → `ERROR` と表示。

**実行前提**：Node.js 22.16.0、Linux（コンテナ）、headless Chromium（システム実行ファイル）。Node.jsとChromiumの実験はCPU上で実行される。GPU・混合精度・実モデル学習は検証対象外。

**再実行コマンド**：`npm run check:browser`。Node.js 41テスト、Chromiumの既存27チェック＋失敗比較の追加1チェックが通過。`npm run test:e2e` は実行を試みたが、ローカルHTTPへのChromium画面遷移が管理環境の `net::ERR_BLOCKED_BY_ADMINISTRATOR` で遮断された。この失敗はサーバー機能の不具合を示すものではなく、HTTP画面操作は引き続き未検証。Node.jsのHTTP APIテストは通過。

**H（反証可能な仮説）**：不完全な記録は採点されず、偽の共通課題定義が公開されず、係数変更後の範囲外停止時にも前回の経路を観察できる。

**T（最小検証）**：単体・HTTP API・Chromium操作をそれぞれ決定的な入力で実行。最小1反例で不具合を確認し、修正後に全回帰テストを実行。タイムアウトを含む異常終了はFAILとして扱う。

**D（判定）**：対象の入力で各期待値を満たし回帰テストが0失敗ならPASS。通常HTTPブラウザの投稿→表示→削除は環境制約によりUNCERTAIN。

**C（破れ方）**：異なるブラウザ、公開HTTPS、サーバーレスストレージ、あるいは競合する投稿・閲覧によって別の不具合が現れる可能性がある。共通課題の形式が正しくても、自己申告スコアの真実性は証明されない。

**U（不確かさ）**：これは決定的な回帰試験であり、性能測定値や統計推定量の測定ではない。したがって合成標準不確かさ `u_c` と包含係数 `k` は定義していない。数値演算はJavaScript Number（IEEE 754倍精度）で、ブラウザ・端末によるMath実装差を除外できない。

証跡画像：`docs/screenshots/failed-beta-comparison.png` と `docs/screenshots/failed-beta-comparison-mobile.png`。実ユーザーの操作性調査、Firefox/Safari、独立したセキュリティ監査は未実施。

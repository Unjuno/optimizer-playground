## v0.2.0 — 初期実装の範囲

## 完成した利用動線

地形と更新規則を編集 → ブラウザ内で実際に最適化 → 空間・時間の両方で観察 → 固定条件のチャレンジ → 希望した場合のみコードと結果を共有 → 秘密キーで削除。

単体HTMLでは投稿API以外を利用できます。サーバー版では投稿APIを同梱しています。サーバーが利用者の最適化計算を肩代わりする設計ではありません。

## 原案との差分・実装判断

| 論点 | この版の判断 | 代償／未対応 |
|---|---|---|
| ブラウザ完結 | CPUのFP64で計算 | GPU未実装 |
| 任意の更新則 | 制限付きJSの関数・ループ・配列・自由な状態を提供 | 完全JS、Python、外部ライブラリは非対応 |
| 視覚編集 | 部品設定から実行コードを生成し、適用前のコードに戻せる | 汎用の接続変更や任意コードの逆変換は未対応 |
| シミュレーション | 実際の2D目的関数評価と解析勾配 | NN学習、高次元行列タスク、Muonの性能評価は未対応 |
| 公開 | HTTPサーバー・共有URL・削除APIを実装 | インターネットへのデプロイは未実施 |
| GitHub | リポジトリ用ソースとCI構成を用意 | 接続ツールが読取り専用のためcreate/push未実施 |
| スコア | 改善度と評価コールのゲーム用指標 | 不正防止・独立再実行・公式順位はなし |
| 保存 | 明示的投稿のみ、個人用保存なし | 再読込で未投稿の編集は消える |
| ライセンス | 所有者の選択待ち | 公開前にライセンスを決める必要あり |

## 未解消の検証範囲

Chromiumの本環境ではURLナビゲーションが管理ポリシーで禁止されています。そのポリシーは変更していません。実HTMLをブラウザ内に直接読み込ませたUI/Workerテストと、Node経由で実際のHTTP APIを呼ぶテストを実施しました。**ホスト版の共有→別タブ閲覧→削除のブラウザHTTP一貫テストは、この環境では完遂していません。** 通常環境用のテストスクリプトを同梱しています。

Firefox/Safari、実端末のタッチ操作、実GPU、Dockerの起動、公開HTTPSサイト、独立セキュリティ監査は未検証です。

## 次の変更に向けて

数値エンジン、インタープリター、UI、共有APIを別ファイルに分けました。ランタイムの互換性や採点プロトコルを変更した際は、版番号を上げて古い共有結果と混同しないでください。難しい地形での失敗例も共有できる設計を維持し、単一スコアだけで探索を狭めない方針です。

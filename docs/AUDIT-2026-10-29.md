# 2026-10-29 UI・操作・実装レビュー

対象: GitHub公開準備用の Optimizer Playground v0.2.0。静的単体HTMLとNode.js共有APIを含む。レビューによる変更は**機能仕様やスコア定義を変更しない**。

## 現状評価

- **主要操作**: 損失地形の生成、カスタム数式とブラシ、複数オプティマイザのシミュレーション、履歴再生、コード／部品編集、9ケースの共通課題が動作することをブラウザで確認。
- **UI**: PCでは三列の実験ビューが整理されている。一方、モバイルでは説明へ進めない／文字・操作部品が小さい問題を再現した。
- **スコアと共有**: スコアは自己実行・未検証。単体HTMLには投稿APIがなく、実際の共有はNode.jsサーバー版が必要。

## 修正した問題

1. **モバイルで「使い方」を開けない**: 1020px以下でナビ全体が非表示だった。小画面では「使い方」のみヘッダーに表示するよう修正。320 / 390 / 768pxでも確認。
2. **文字とタッチ領域が小さすぎる**: 左側の設定、ツール、状態表示、コードエディタを12px以上に、主要モバイル操作を高さ40px以上に調整。小画面の地形ツールバーは横スクロール可能とし、ページ全体は横にはみ出さない。
3. **視覚編集後の手入力がUndoで消える**: 生成したコードを手動変更すると、古いUndoを無効に変更。
4. **Undo後に手法表示が「自作」のまま残る**: 元のコードに加え、選択済みの手法名も復元するよう変更。
5. **Undoの説明が実際の有効期間と違う**: 「コードを手で編集するまで使える」と明記。

## 自動テストの範囲

- Node.js (`npm test`): エンジン、地形式、インタープリターの制限、データ形式、CSV、ビルド、共有HTTP API。
- Chromium (`npm run test:browser-offline`): 単体HTMLを読み込み、UIと実際のWeb Workerの計算・再生・編集を検証。外部通信ゼロ。
- `npm run test:e2e` は、このレビュー環境では `net::ERR_BLOCKED_BY_ADMINISTRATOR` でHTTPローカルナビゲーションが遮断された。**ブラウザのHTTP共有フローを通したとは報告しない**。公開前に実環境で確認する。

## 残す制限・次の調整候補

- **設計**: 情報密度が高く、初めての参加者向けには「最初の一歩」だけを操作する導入ビューがあるとよい。既存編集機能を削らず別ビューで設計する。
- **アクセシビリティ**: ブラシによる手描きとキャンバス上の軌跡は、スクリーンリーダー・キーボードだけで等価に操作できない。今回のフォント改善はWCAG適合を意味しない。
- **研究上の厳密性**: 公開済みの9課題は過剰適合し得る。ランキング・実学習の優劣を主張するには、独立検証や非公開課題が必要。
- **セキュリティ**: 自作JSは制限付きインタープリターとWorkerで実行しているが、独立したセキュリティレビューは未実施。共有閲覧時のコードは自動実行しない。
- **Work/Sitesへ移す場合**: 現在のファイル保存型サーバーのデータ永続性、APIルート、負荷・削除用鍵の取り扱いを移行先で再設計する。GitHub公開およびSitesデプロイは、このレビューでは実施しない。
- **計算バックエンド**: v0.2.0はCPU/FP64の2変数シミュレーション。WebGPU、任意Python/CUDA、実際のモデル学習は未対応。

このレビューは実装者による自己レビューと自動試験であり、独立した第三者監査ではない。
